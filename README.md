Brainrot Bonanza — a 3D Roblox brainrot game. Meme brainrots walk down the central conveyor: buy one with E and it moves to your base and earns cash every second. Hold E on another player's brainrot to steal it, then dash home before they slap you (F). Rebirth for a permanent income multiplier, and run to your base when the Brainrot Tsunami warning sounds. Twelve brainrots across six rarities (Common to Secret), Golden / Diamond / Rainbow mutations, eight coloured base plots, a live leaderboard and a full HUD.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Open `game.rbxl` in Roblox Studio and press Play. To hand the entry in, run the kit's program from this directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `game.rbxl`, `src/`, `screenshots/` and `PLAY.json` to the output directory and writes `dossier.json` with the vendored make.fun library.

## How it is built

- `default.project.json` — the Rojo project: the 3D world (conveyor lane, 8 base plots, spawn, totem, trees, lamps, boundary walls, tsunami wall) plus the script layout. Generated by `gen_project.py`.
- `src/shared/Config.luau` — every number both sides agree on: the 12-brainrot catalogue, rarity weights, mutations, steal/rebirth/wave rules, base positions.
- `src/server/Brainrot.server.luau` — the whole game state: conveyor spawning, buying, stealing and carrying, slapping, rebirths, earnings ticks, the Brainrot Tsunami wave, leaderstats.
- `src/client/Hud.client.luau` — every screen the player sees: start screen, HUD, collection panel, leaderboard, rebirth + slap buttons, wave banner, notifications.
- `PLAY.json` — names the published place (place_id / universe_id). It is a placeholder until the game is published as a Public experience on Roblox; the gate refuses an entry whose play link is not Public.

## Controls

WASD / arrow keys to move, Space to jump. E to buy (or hold E to steal). F to slap a nearby player. The game works on desktop and mobile.
